# Miareve Study Guard

**제작자 Miareve · 베타 1.0.0Ver**

디자인·After Effects 공부에서 벗어나면 **“공부 안할거냐?”** 라고 알려주는 Windows 데스크톱 앱입니다.

## 다운로드와 시작

1. 저장소의 `MiareveStudyGuard.exe`를 선택하고 **Download raw file**로 다운로드합니다. 또는 아래 실행 파일 링크를 사용하세요.
2. `MiareveStudyGuard.exe`를 실행합니다. 별도 설치 없이 실행되며 화면 접근은 기본으로 꺼져 있습니다.
3. **화면 보기 허용 (현재 실행 중에만)**을 체크합니다.
4. 공부 이탈 알림까지 기다릴 시간을 설정합니다. 기본 **5분**, 범위 **1–60분**입니다.
5. **공부 시작**을 누르고 작업 앱이나 강의 창으로 이동하세요.

[실행 파일 다운로드](https://github.com/wa13sans/miareve-study-guard/raw/refs/heads/main/MiareveStudyGuard.exe)

Windows 10/11 데스크톱 및 .NET Framework 4.8 환경을 대상으로 합니다. 현재 실행 파일은 디지털 코드 서명이 없는 베타입니다.

## 기능

- After Effects, Illustrator, Blender, Unity, Photoshop의 활성 프로세스 인식
- 브라우저 등 활성 창 제목의 공부 키워드 확인, 사용자 키워드 편집
- 5초 주기의 로컬 화면 변화 분석 및 마지막 키보드·마우스 입력 이후 시간 확인
- 공부와 관련된 창이면서 최근 3분 이내 입력 또는 화면 변화가 있으면 공부 중으로 추정
- 연속 공부 이탈 시간이 설정값에 도달하면 알림 표시; 공부로 돌아오면 이탈 시간 초기화
- **알림 테스트**, **10분 쉬기**, **일시 정지**, 트레이 메뉴
- 20초 뒤 알림 자동 닫기, 설정된 간격으로 재알림, 다른 앱의 입력 포커스를 빼앗지 않는 알림
- 화면 잠금·절전 복귀 때 보지 못한 시간을 이탈 시간으로 누적하지 않음
- X 버튼과 트레이의 종료 메뉴는 완전 종료. 자동 실행 등록 없음

## 화면 접근 플러그인과 개인정보

`src/ScreenAccessPlugin.cs`는 독립 DLL로 빌드한 뒤 EXE 안에 포함하는 내장 플러그인입니다. EXE 하나만 옮겨도 함께 작동합니다. Chrome 확장 프로그램이나 Codex 플러그인이 아닙니다.

- 매 실행마다 사용자가 허용해야 하며, **공부 시작** 후에만 분석합니다.
- 활성 창이 있는 **모니터 전체**를 메모리로 캡처합니다. 다른 창이 같은 모니터에 보이면 함께 포함될 수 있습니다.
- 캡처 이미지는 디스크에 저장하지 않습니다. 64×36 픽셀의 변화 비교용 배열만 다음 검사까지 메모리에 유지합니다.
- 창 제목·이미지·활동 기록을 서버나 AI 서비스에 전송하지 않습니다. 네트워크 통신과 계정·API 키가 필요 없습니다.
- 허용 해제, 일시 정지, 휴식, 화면 잠금, 종료 시 화면 비교 데이터를 초기화합니다.
- 입력 내용과 키 자체는 수집하지 않고, 마지막 입력 이후 경과 시간만 확인합니다.
- 설정·공부 시간은 현재 실행 중에만 유지됩니다. 재실행하면 초기화됩니다.

## 정확도와 제한

이 버전은 **규칙 기반 추정**입니다. AI 비전이나 OCR로 공부 내용을 이해하지 않습니다. 관련 창 제목을 가진 오락 영상이나 관련 앱 안에서의 딴짓은 구분하지 못할 수 있습니다. 반대로 3분 이상 입력 없이 정지된 자료를 읽는 경우 공부 이탈로 판단할 수 있습니다. 알림 대기 시간을 늘리거나 키워드를 추가하세요. 영상 강의는 관련 키워드와 화면 변화가 있으면 입력이 없어도 공부로 봅니다.

화면 전체의 변화이므로 같은 모니터의 다른 애니메이션이 판단에 영향을 줄 수 있습니다. 보호된 영상, 보안 화면, 원격 세션에서는 캡처가 제한될 수 있습니다. 감지 실패 시 분석을 중지하고 오류 상태를 표시합니다. 이 앱은 작업을 차단하거나 강제로 종료하지 않습니다.

## 소스에서 빌드

Windows PowerShell에서 이 폴더를 열고 실행합니다.

```powershell
.\build.ps1
```

Windows에 있는 .NET Framework C# 컴파일러를 사용합니다. 추가 패키지를 다운로드하지 않습니다. 결과는 `MiareveStudyGuard.exe`이며 판단 규칙·권한 기본값에 대한 15개 검사를 실행합니다.

`tests/UiTests.cs`에는 내장 플러그인 로드, 동의, 시작, 휴식, 허용 해제, 알림창을 확인하는 8개 UI 통합 검사도 포함되어 있습니다. 이 검사는 실제 화면 수집 타이머를 끈 상태에서 수행합니다.

## 파일 구성

- `src/App.cs`: 한국어 앱 화면, 알림, 트레이, 권한·세션 관리
- `src/StudyPolicy.cs`: 공부 추정 규칙과 시간 누적
- `src/ScreenAccessPlugin.cs`: 동의 기반 화면 변화 분석 모듈
- `tests/`: 판단 규칙 및 UI 통합 검사
- `build.ps1`: Windows 빌드 및 기본 검사
